# Stock

ระบบตัวอย่างสำหรับจัดการสต๊อกสินค้าทดลอง โดยรองรับ:

- ตั้งค่าสินค้าเริ่มต้น 4 รายการ
- บันทึกรายชื่อผู้มีสิทธิ์เบิก (และเพิ่มได้ในอนาคต)
- การเบิกสินค้า: ระบุผู้เบิก, ลูกค้า/บริษัท, โครงการ/สถานที่, วัตถุประสงค์, วันที่เบิก, รายการสินค้า
- ตัดสต๊อกทันทีเมื่อเบิก
- การรับคืนสินค้า: ต้องระบุชื่อทีมงานผู้รับคืน

## ใช้งานผ่านหน้า HTML (แนะนำ)

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์
2. รันคำสั่ง:

```bash
python web_app.py
```

3. เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8000`
4. ใช้งานได้จากหน้าเดียว:
   - ดูสินค้าและจำนวนคงเหลือ
   - เพิ่มสินค้า
   - เพิ่มผู้เบิก
   - เบิกสินค้า
   - คืนสินค้า
   - ดูประวัติการเบิก/คืน

หมายเหตุ: การทำงานของหน้าเว็บใช้กฎธุรกิจเดิมจาก `stock_system.py`

รันเทสต์:

```bash
python -m unittest -v
```
